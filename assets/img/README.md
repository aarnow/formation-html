# Vos images

Elles se rangent ici.

**Nommage** — minuscules, sans accent ni espace, un trait d'union entre les
mots : `photo-profil.webp`, et non `Photo Profil.PNG`.

**Format et poids** — WebP, sous 200 Ko. [Squoosh](https://squoosh.app/) fait la
conversion et le redimensionnement dans le navigateur, sans rien installer.

**Dimensions** — notez la largeur et la hauteur du fichier final : elles vous
serviront pour les attributs `width` et `height` de la balise `<img>`.
